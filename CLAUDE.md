# Vehicle Service Due Predictor

When implementing features for this workshop app, always follow the domain rules and scoring requirements described in `README.md` and `AGENTS.md`.

Key reminders:

- Distance based service items must be estimated from each vehicle's daily running distance.
- Completing a service resets only that item and appends to history.
- The daily call list must be sorted by a clear rule (overdue first, then value).
- Required features come before bonus features.
